# PEKP static audit — 2026-09-30

Literature cutoff: **2026-09-30**. This note records the static literature and repository review for that cutoff, with selected publication metadata, repository redirects, file trees and documentation rechecked on **2026-10-01**. It is a focused audit, not a complete reproduction study. No model inference, training or benchmark was run; task checkpoints and Git LFS payloads were not loaded.

The [collection](../README.md) retains all 90 previous category records. Four additional models, an MPEK derived-ratio entry and eight Ki entries bring the section counts to **46 kcat / 34 Km / 15 kcat/Km / 8 Ki**. A method appearing under multiple targets is intentional.

## Targets, aliases and status corrections

- **ERBA:** add the [CVPR 2026 proceedings source](https://openaccess.thecvf.com/content/CVPR2026/html/Wang_Multimodal_Protein_Language_Models_for_Enzyme_Kinetic_Parameters_From_Substrate_CVPR_2026_paper.html) while retaining [arXiv:2603.12845](https://arxiv.org/abs/2603.12845). Its three kinetic endpoints are kcat, Km and Ki. The proceedings link was identified in the cutoff review; the 2026-10-01 automated request returned 403, while the arXiv text remained readable.
- **MPEK:** the [2024 paper](https://doi.org/10.1093/bib/bbae387) evaluates catalytic-efficiency ratios in case studies by dividing predicted kcat by predicted Km. Its new kcat/Km row therefore describes a derived output, not a separately trained ratio model. [Implementation](https://github.com/kotori-y/mpek).
- **OmniESI:** add [arXiv:2506.17963](https://arxiv.org/abs/2506.17963). The old [MESI repository URL](https://github.com/Hong-yu-Zhang/MESI) redirects to [OmniESI](https://github.com/Hong-yu-Zhang/OmniESI), rechecked on 2026-10-01. This establishes a repository rename, not identity between every manuscript version.
- **SAKPE:** link the [2025 preprint](https://doi.org/10.1101/2025.04.30.651216) separately from the [repository](https://github.com/HGzyme/SAKPE). The inspected repository contains only a seven-byte, title-only `README.md`; it is a placeholder, not released implementation code.
- **Ki:** the inhibition constant is distinct from Kd and IC50. The eight rows are supported by [CatPred](https://doi.org/10.1038/s41467-025-57215-9), [OmniESI](https://arxiv.org/abs/2506.17963), [CPI-Pred](https://doi.org/10.1101/2025.01.16.633372), [SAKPE](https://doi.org/10.1101/2025.04.30.651216), [ERBA](https://arxiv.org/abs/2603.12845), [EnzCast](https://doi.org/10.64898/2026.04.28.721430), [GAPEK/GAPEK+](https://doi.org/10.1021/acs.jcim.6c02546) and [EnzGFM](https://doi.org/10.1038/s41467-026-75283-3). EnzGFM's Ki result uses **CatPred downstream**; its UniKP downstream entries remain in the other three sections. No Ki support is inferred merely from a binding-affinity task or a slash-separated list of parameters.
